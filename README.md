# 📱 Mobile CRUD

Este repositório contém o código-fonte do aplicativo mobile desenvolvido para interagir com uma API de Back-end, permitindo as operações básicas de CRUD (Create, Read, Update, Delete).

## ✨ Tecnologias Utilizadas

Este projeto mobile foi construído utilizando as seguintes ferramentas:

* **Framework:** React Native
* **Plataforma:** Expo (ou CLI padrão, ajuste se necessário)
* **Linguagem:** JavaScript / TypeScript (ajuste se for TS)
* **Biblioteca de Requisições:** Axios ou Fetch (ajuste se for diferente)

## 🛠️ Como Instalar e Rodar o Projeto

### 1. Clonar o Repositório

Abra o terminal e clone o projeto:

```bash
git clone [https://github.com/WedjaSousa/Mobile.CRUD.git](https://github.com/WedjaSousa/Mobile.CRUD.git)
cd Mobile.CRUD
```

### 2. Instalar Dependências

```bash
npm install
```

### 3. Iniciar o Aplicativo

```bash
npm start
```

### 4. Acessar o App

Após o comando, o terminal irá exibir um QR Code.
- Com Expo Go: Use a câmera ou o aplicativo Expo Go no seu celular físico para escanear o QR Code.
